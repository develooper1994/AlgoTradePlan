# Phase 18 — Autonomous Real-Data Self-Boot Pipeline

## Goal
Enable self-boot execution without manual "continue" commands and validate real upstream data coverage.

## Requirements
- `scripts/run_all_phases.py` drives checkpoints `V0` -> `Vfinal` automatically.
- `scripts/e2e_real_data_smoke.py` auto-discovers assets per source and validates coverage for tick/kline/trade/orderbook/funding plus news/macro pulls.
- E2E flow includes ingestion, feature build, strategy optimization, signal/intent, risk, and portfolio update.
- Notebook walkthrough available in `notebooks/algotrade_e2e_demo.ipynb`.
