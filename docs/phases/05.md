# Phase 05 — Ingestion, Storage, Quality, and Provenance

## Goal
Deliver the first extensible ingestion pipeline that can be expanded safely in later phases.

## Requirements
- route normalized batches through quality, storage, and provenance plugins
- reject invalid or empty batches
- preserve storage receipts and revision metadata

## Validation Checklist
- [ ] ingestion pipeline wires source, quality, storage, and provenance
- [ ] quality failures stop the pipeline
- [ ] provenance captures request and storage lineage
