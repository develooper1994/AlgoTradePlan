# Contributing

## Branch and PR Rules
- Keep PRs small and focused.
- Include tests for behavior changes.
- Follow semantic versioning impact notes.

## Code Sharing and PR Checklist
- No secrets/PII in commits.
- Add/adjust docs when behavior changes.
- Run `make test` and `make smoke` before opening PR.

## Local Commands
```bash
make bootstrap
make lint
make test
```
